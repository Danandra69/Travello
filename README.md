# 🧭 Travello (Website Travelling Sederhana)

Travello adalah website travelling sederhana yang dibuat menggunakan React + Tailwind CSS, dirancang untuk menampilkan destinasi, tips perjalanan, serta informasi tentang Travello.

## 🚀 Fitur Utama

1. 🏠 Homepage

- Hero banner dengan gambar destinasi
- Tombol "Lihat Destinasi" & "Mulai Sekarang"
- Kategori populer (Pantai, Gunung, Kota)
- Rekomendasi destinasi lokal

2. 🧭 Halaman Destinasi

- Daftar destinasi populer
- Foto + deskripsi singkat
- Responsive grid layout
- Scroll ke atas otomatis saat berpindah halaman

3. 💡 Halaman Tips

- Tips perjalanan sederhana
- Tips hemat, persiapan, hingga keamanan
- Tampilan ringkas & mudah dibaca

🧾 4. Halaman About

- Penjelasan tentang Travello
- Visi & Misi
- Alasan memilih Travello
- Penutup

📱 5. Navbar Responsif

- Menu desktop lengkap
- Hamburger menu untuk mobile (Android)

## 📜 Lisensi

Project ini dibuat untuk keperluan belajar dan tugas kecil. Bebas digunakan, dimodifikasi, dan dikembangkan.
